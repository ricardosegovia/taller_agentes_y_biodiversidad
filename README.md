# Taller Agentes y Biodiversidad

Este repositorio centraliza el desarrollo del taller internacional sobre agentes de inteligencia artificial y biodiversidad.

## Contenido actual

- Manuscrito del programa de trabajo en [ms_programa](ms_programa/)
- Materiales de apoyo y productos en desarrollo en [docs](docs/)
- Notas de trabajo y borradores en [notes](notes/)

## Estructura propuesta

- [ms_programa](ms_programa/): fuente del manuscrito y materiales del programa de trabajo
- [docs](docs/): documentos, referencias y productos compilados
- [notes](notes/): notas de reunión, ideas y borradores
- [data](data/): datos o recursos auxiliares cuando se incorporen

## Compilación del manuscrito

Para compilar el documento LaTeX actual:

```bash
cd ms_programa
pdflatex manuscrito_outline_taller_agentes_biodiversidad.tex
```

Este repositorio está pensado para crecer con el desarrollo del taller, incorporando materiales, protocolos, referencias y productos colaborativos.
